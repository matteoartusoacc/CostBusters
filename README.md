## Progetto: CostBusters — trasparenza dei costi d'investimento

Progetto per l'hackathon di ottobre 2026. Tema: **inclusione finanziaria**.

CostBusters analizza prospetti finanziari e report di consulenza e porta in superficie i costi, espliciti e impliciti, che un investitore comune non riesce a vedere né a quantificare.
